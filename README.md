# Project Setup & Architecture

This repository contains the foundational structure for the application, following a clean architecture and separation of concerns.

## Directory Structure

- `frontend/`: React 19 application with TypeScript, Tailwind CSS, and Material-UI (MUI).
- `backend/`: Flask application with Python 3.11.
- `database/`: Database migration scripts, schemas, and seed data.
- `docker/`: Containerization configurations and Dockerfiles.
- `tests/`: Integration, end-to-end, and cross-cutting tests.
